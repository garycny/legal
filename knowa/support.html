常见问题

更改货币会换算金额吗？

不会。Knowa 只更新货币符号和显示格式，不会改变已经记录的金额数值。

备份文件保存在哪里？

打开“设置 → 数据管理 → 导出备份”。导出时由你选择保存位置，可以存入 iCloud Drive、本机文件或其他支持系统分享的应用。备份包含资产和历史记录，请妥善保管。

Knowa 会上传我的资产吗？

不会。资产数据默认只保存在本机。只有你主动导出、分享，或使用 Apple 语音识别等系统服务时，相应信息才会按照你的操作离开应用控制范围。

如何恢复 Knowa Pro？

进入“设置 → Knowa Pro”，点按“恢复购买”，并使用最初购买时的 Apple 账户。Knowa Pro 是一次性非消耗型 App 内购买，不是订阅，也不会自动续费。

语音更新或截图识别无法使用怎么办？

请先至少创建一项资产。语音更新需要在系统设置中允许麦克风和语音识别；截图识别只读取你通过系统照片选择器选中的图片，并使用 Apple Vision 在设备上识别文字。识别结果保存前仍需由你确认。

合并导入和覆盖现有数据有什么区别？

合并导入会更新备份中可匹配的资产并保留其他数据；覆盖会先清除当前资产与历史记录，再写入备份内容。覆盖前请先导出一份可用备份。

如何删除全部数据？

进入“设置 → 数据管理 → 清除所有数据”。该操作会永久删除全部资产和历史快照，无法撤销；如需保留数据，请先导出备份。

Frequently Asked Questions

Does changing currency convert amounts?

No. Knowa changes only the currency symbol and display format, not the numeric values you recorded.

Where is my backup saved?

Open Settings → Data Management → Export Backup. You choose the destination, including iCloud Drive, On My iPhone, or another app in the share sheet. Backups contain assets and history, so keep them secure.

Does Knowa upload my assets?

No. Asset data stays on your device by default. Information leaves the app’s control only when you export or share it, or deliberately use a system service such as Apple speech recognition.

How do I restore Knowa Pro?

Open Settings → Knowa Pro and tap Restore Purchase while using the Apple Account that made the original purchase. Knowa Pro is a one-time, non-consumable In-App Purchase—not a subscription—and does not renew automatically.

Why is voice or screenshot recognition unavailable?

Create at least one asset first. Voice Update requires Microphone and Speech Recognition permission in system Settings. Screenshot Recognition reads only an image you select with the system photo picker and uses Apple Vision on-device. You still approve the result before saving.

What is the difference between Merge and Replace import?

Merge updates assets that can be matched from the backup and keeps other data. Replace clears current assets and history before importing the backup. Export a usable backup before replacing data.

How do I delete all data?

Open Settings → Data Management → Clear All Data. This permanently deletes every asset and history snapshot and cannot be undone. Export a backup first if you need to keep the data.

Knowa 지원

Knowa는 로컬 우선 개인 자산 관리 앱입니다. 도움이 필요하면 아래의 자주 묻는 질문을 확인하거나 이메일로 문의해 주세요.

이메일 문의 support@gridnet.top
01

로컬 우선

자산, 부채 및 기록은 기본적으로 기기에 저장됩니다. Knowa는 계정을 요구하지 않고 은행에 연결하거나 자산 동기화 서버를 운영하지 않습니다.

02

권한은 사용자가 관리

마이크와 음성 인식은 음성 업데이트에, 선택한 이미지는 기기 내 문자 인식에, 생체 인증은 앱 잠금 해제에만 사용됩니다.

03

백업은 사용자가 보관

직접 내보낼 때만 JSON 백업이 생성됩니다. 저장 위치는 사용자가 선택하며 데이터 관리에서 모든 로컬 데이터를 삭제할 수 있습니다.

자주 묻는 질문

통화를 변경하면 금액도 환산되나요?

아니요. Knowa는 통화 기호와 표시 형식만 변경하며 이미 기록된 금액의 숫자는 바꾸지 않습니다.

백업 파일은 어디에 저장되나요?

설정 → 데이터 관리 → 백업 내보내기를 여세요. iCloud Drive, 나의 iPhone 또는 공유 시트의 다른 앱 중에서 저장 위치를 선택할 수 있습니다. 백업에는 자산과 기록이 포함되므로 안전하게 보관해 주세요.

Knowa가 내 자산을 업로드하나요?

아니요. 자산 데이터는 기본적으로 기기에만 저장됩니다. 직접 내보내거나 공유하거나 Apple 음성 인식과 같은 시스템 서비스를 사용한 경우에만 해당 정보가 앱의 관리 범위를 벗어납니다.

Knowa Pro를 어떻게 복원하나요?

설정 → Knowa Pro에서 처음 구매할 때 사용한 Apple 계정으로 구매 복원을 누르세요. Knowa Pro는 한 번 구매하는 비소모성 앱 내 구입이며 구독이 아니므로 자동 갱신되지 않습니다.

음성 업데이트 또는 스크린샷 인식을 사용할 수 없어요.

먼저 자산을 하나 이상 만들어 주세요. 음성 업데이트에는 시스템 설정의 마이크 및 음성 인식 권한이 필요합니다. 스크린샷 인식은 시스템 사진 선택기에서 고른 이미지만 읽고 Apple Vision으로 기기에서 처리합니다. 저장 전 결과를 직접 확인해야 합니다.

병합 가져오기와 기존 데이터 교체의 차이는 무엇인가요?

병합은 백업에서 일치하는 자산을 업데이트하고 다른 데이터는 유지합니다. 교체는 현재 자산과 기록을 먼저 삭제한 뒤 백업을 가져옵니다. 교체 전에는 사용 가능한 백업을 내보내세요.

모든 데이터를 삭제하려면 어떻게 하나요?

설정 → 데이터 관리 → 모든 데이터 지우기를 여세요. 모든 자산과 기록이 영구 삭제되며 되돌릴 수 없습니다. 데이터를 보관해야 한다면 먼저 백업을 내보내세요.
